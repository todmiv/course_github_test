# Course GitHub Test

This repository is a test project for learning Git and GitHub workflows.

## Description

The project contains solutions to various problems, organized in different branches:

- Problem 1: Basic Git operations
- Problem 2: Branching strategies
- Problem 3: Merge conflicts and collaboration

## Branches

- `main`: Main branch with stable code
- `develop`: Development branch
- `task1`: Branch for task 1
- `2-problem-1`: Solution for problem 1
- `3-problem-2`: Solution for problem 2
- `4-problem-3`: Solution for problem 3

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/todmiv/course_github_test.git
   ```

2. Navigate to the directory:
   ```bash
   cd course_github_test
   ```

3. Install dependencies (if any):
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the project:
```bash
python main.py
```
